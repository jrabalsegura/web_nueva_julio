# Sustitucion de imagenes

Esta carpeta esta preparada para incorporar fotos reales de trabajos de Resolution Solar Energy.

Recomendacion de nombres:

- `fotovoltaica-cubierta-01.jpg`
- `fotovoltaica-industrial-01.jpg`
- `drone-termografia-paneles-01.jpg`
- `hvac-sala-tecnica-01.jpg`
- `aerotermia-suelo-radiante-01.jpg`
- `cuadro-electrico-01.jpg`
- `cargador-ve-residencial-01.jpg`
- `mantenimiento-solar-01.jpg`

En `proyectos.html`, cada tarjeta incluye `data-photo-slot` y un comentario HTML con la foto sugerida. Para sustituir un placeholder, cambia el bloque `.placeholder` por una imagen real:

```html
<img src="assets/img/placeholders/fotovoltaica-cubierta-01.jpg" alt="Instalacion fotovoltaica en cubierta inclinada">
```

Mantener textos `alt` descriptivos ayuda a la accesibilidad y al SEO.
