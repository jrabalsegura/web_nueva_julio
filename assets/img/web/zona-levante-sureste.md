# Mapa de cobertura

`zona-levante-sureste.svg` utiliza geometría de España y Portugal de Natural Earth, escala 1:50m, transformada a coordenadas SVG. Muestra España peninsular y Baleares. La franja amarilla es una representación orientativa de Levante y el sureste, no una delimitación administrativa ni ubicaciones de oficinas.

- Datos: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson
- Licencia: dominio público, https://www.naturalearthdata.com/about/terms-of-use/
- El archivo se sirve localmente, sin mapas externos, claves API ni peticiones a un proveedor cartográfico.
